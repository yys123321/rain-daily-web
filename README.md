# 雨姐的日常

这是一个基于静态网页的视觉小说 Demo，适合电脑和手机浏览器直接访问。

## 快速启动

1. 打开仓库根目录中的 `index.html`
2. 用浏览器直接打开即可运行
3. 也可以上传到 GitHub Pages / Netlify / Vercel

## 说明

- 这是一个可演示原型，不包含正式商业发行素材
- 角色立绘目前使用了程序生成的占位风格，便于后续替换成你自己的图片
- 未来可以直接替换成真实的：
  - 去白底角色图片
  - 角色配音
  - 背景音乐
  - 章节剧情数据

## 目录结构

- `index.html`：页面入口
- `styles.css`：界面样式
- `script.js`：故事逻辑与存档
- `data/dialogue.json`：剧情内容
- `audio/`：音效和背景音乐目录（需要你补充）

## GitHub Pages

在 GitHub 仓库中开启 Pages 后，网页会生成类似：

https://yys123321.github.io/rain-daily-web/

如果你还没有开启 Pages，请进入：

- GitHub 仓库页面
- `Settings`
- `Pages`
- Source 选择 `Deploy from a branch`
- Branch 选择 `main`
- Folder 选择 `/ (root)`

然后保存即可。
